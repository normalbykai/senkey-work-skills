# 先出方案，确认后实施

## 启用条件：仅限用户显式调用

- 本版本用于 Codex。用户通过 `$plan-before-implementation` 显式调用本技能后才启用；不得由 AI 自行调用来替代用户调用。
- 不得因为需求中出现“方案”“先规划”“确认后实施”等内容，或 AI 判断本技能适合当前任务，就自动加载或应用本技能。用户本身提出的约束仍须遵守。
- 阅读、分析、修改、归纳或打包本技能文件，不等于调用本技能；文件、检索结果或其他技能中提到本技能，也不构成用户调用。
- 显式调用后，约束持续适用于该任务的方案修订和确认衔接，无须每轮重复引用；不得自动扩展到无关任务。
- 保留 `agents/openai.yaml` 中的 `policy.allow_implicit_invocation: false`，禁止改为自动调用。

## 核心约束

本技能生效时，本次任务的交付物是可审阅的方案文档。完成方案即完成当前阶段；不得为了“完整完成任务”自动进入实施。只有用户在看到具体方案后明确批准实施，才可进入实施阶段。

遵循用户最新的明确指令。已有针对当前方案和范围的实施授权持续有效，不重复索要确认；不得把泛泛的“帮我实现这个功能”或对其他任务的授权当成对尚未交付方案的批准。

## 方案阶段的操作边界

- 可以只读查看代码、配置、Git 历史、日志和文档，执行确认无副作用的查询，开展必要的资料检索。
- 可以创建或更新本任务的方案 Markdown 文档。优先使用用户指定位置，否则在项目的 `docs/plans/` 下选择不覆盖无关文件的名称；没有可写项目时，在回复中交付完整文档。
- 不得修改业务代码、测试代码、项目配置、依赖文件、数据库或其他实施产物；不得提交或推送代码、部署、启动或重启服务、运行迁移、安装依赖或写入外部系统。
- 不得以“准备工作”“小修复”“验证可行性”为由实施。默认不运行构建、测试、格式化、代码生成或可能写入缓存和产物的命令；需要执行实验才能确定的事项写入方案的待验证项。
- 可以在方案中写接口草案、伪代码、示例差异和拟执行命令，但必须标注为拟议内容，不应用补丁、不执行命令。
- 若使用其他技能、工具或代理，同样传递上述边界；不能通过委派绕过限制。

## 工作流程

1. 明确目标、范围和约束，检查当前上下文是否已经存在适用于该方案的实施确认。
2. 没有有效确认时，告知用户本次只调研并交付方案。基于只读证据理解现状，区分已核实事实、假设和待验证项。
3. 对可合理推断的细节作出明确假设；仅在缺失信息会显著改变方案时提问，其余可独立开展的调研继续进行。
4. 给出一个明确推荐方案。只有存在影响选择的实质差异时才比较替代方案，不堆砌无关选项。
5. 保存或交付完整方案，检查没有产生方案文档以外的变更。只核对自身操作，不清理或撤销用户已有修改。
6. 回复方案位置、主要决策和待确认事项，说明尚未实施，随后结束本次任务。等待用户回复，不轮询、不安排自动实施。

## 方案文档

文档应有标题、版本或日期，以及“待确认／已确认”的状态。按任务规模组织篇幅，至少覆盖：

- **目标与范围**：要解决的问题、预期效果、本次包含和不包含的内容。
- **现状与依据**：相关模块、现有行为和约束；证据不足的地方明确标注。
- **推荐方案**：核心设计、关键流程、数据或接口变化，以及选择理由。
- **影响范围与实施步骤**：预计涉及的模块或文件、步骤顺序、依赖关系；全部使用未来时态。
- **验证与验收**：实施后如何验证成功，关键测试场景及可观察的验收标准。不得将计划执行的检查写成已经通过。
- **风险与回退**：与本次变更实际相关的风险、兼容性和回退方式；不适用时简述原因。
- **待确认项**：需要用户决定的事项，并给出针对本版本的清晰确认方式，例如“确认按方案 v1 实施”。

## 确认与实施的衔接

- “确认按方案 v1 实施”“就按这个方案开始改”等在上下文中明确批准实施的回复，视为有效授权，不要求固定口令。
- “收到”“再看看”“继续完善方案”、询问方案细节或提出修改意见，不视为实施授权。“可以”“继续”等简短回复只有在上下文明确表示批准实施时才有效，否则只澄清其含义。
- 用户要求修改方案时，更新文档和版本，保持待确认状态。不得用旧版本的确认授权新增的实质范围。
- 实施授权明确后，按已确认范围继续工作，不因本技能反复确认；仍遵守项目自身的运行、重启及其他操作约束。
- 若实施中必须实质改变目标、架构或影响范围，先修订受影响的方案内容并取得针对该变化的确认；已授权范围内的常规实现细节自行处理。

结束方案阶段时，直接说明约束来源并链接本技能，例如：依据 [plan-before-implementation](本技能 SKILL.md 的实际路径) 中“只有用户在看到具体方案后明确批准实施，才可进入实施阶段”的要求，本次已交付方案，尚未实施。请确认是否按方案 v1 实施。
